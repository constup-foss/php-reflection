== Description

A set of utilities to make working with PHP's Reflection API easier.

== Installation

[source]
----
composer require constup-foss/php-reflection
----

== Use

Features are documented in docblocks of methods in interfaces. Exact behavior of each method can be viewed in data
providers of test cases.

Available classes:

* link:src/ReflectionService.php[`ReflectionService`]
** Interface: link:src/ReflectionServiceInterface.php[`ReflectionServiceInterface`];
** Tests: link:tests/Unit/ReflectionServiceTest.php[`ReflectionServiceTest`];
